## 2. 新号首局与常用操作

- [x] **NEW-01 · 首次开战**。两种 Web 视口用空档冷启动，角色、武器、敌机图集、战斗界面和场地就绪后直接进入第 1 章第 1 波。分别延迟敌机图集末页和战斗界面图集，等待时配电面板持续播放灯带，波次计时停在起点。放行后灯带随加载页消失，自动开战。下载失败时停止动画，点击「重试加载」重新播放。非调试试玩包也通过首访自动开战和重载验收，原存档可从值班室继续。
- [x] **NEW-02 · 走位与拾取**。进场先不动，底部移动提示清楚可读。默认摇杆在右侧，拖动约 1 秒后提示消失。松手即停，武器自动攻击。铜件进入范围后飞向移动中的角色。基础范围和拾取范围 +30% 分别验证较远铜件是否被吸引，核对每颗只入账一次。
- [x] **NEW-03 · 第一次升级**。清第 1 波后检查「选择升级」的 4 张卡、剩余可选次数和属性说明，点一次只消耗一次选择机会，选完进入商店。
- [x] **NEW-04 · 首店合成**。第 1 波后商店左上格提供一阶电弧扳手。买下后两个扳手槽出现绿点。根据信息条选中武器并点「合成升阶」，两个一阶变为一个二阶。点「开始第 2 波」进入战斗。
- [x] **NEW-05 · 跳过指引**。另开新档，首店点「关闭提示」，提示即时消失。进入下一波再回商店并重启一次，确认指引未重新出现。
- [x] **NEW-06 · 留货、刷新和拆解**。留货一件后刷新，再进入下一波商店，检查留货、价格和铜件余额；取消留货后可替换。免费刷新优先使用，付费刷新按显示价格扣费。拆解武器后到账与按钮一致。若已能留满货架，全留货时刷新入口应禁用。
- [x] **NEW-07 · 满槽和羁绊**。装备六把武器，购买可合成的同阶武器后原槽正确升阶；尝试买无法合成的武器，核对货架和余额。切进「属性与羁绊」检查当前效果，再返回商店，确认武器与货架状态一致。
- [x] **NEW-08 · 工坊、配件排除**。购买一项天赋，检查凭证、升级效果以及进下一局后的实际属性。解锁排除容量后排除一件配件，后续商店刷新并检查其他配件仍能正常出现。

## 3. 章节、难度和结算

- [x] **RUN-01 · 首页剧情**。记录初始 `02:13`、首局推进后尚未通关时 `02:21`、逐章首通后的 `02:38 → 03:05 → 03:32 → 04:05`。检查电台依次交代急救电池及老陈工号、四号楼求救、各站等待合闸、港区老马来电。
- [x] **RUN-02 · 进站、首领与失败文案**。检查切站后进站电台、第 5 波精英及第 12 波首领开场约 4.5 秒的剧情文字，以及前一间商店的战前提示。分别在前 3 波、精英波、首领战阵亡，核对结算电台与阶段相符。另让首领战倒计时归零，检查「首领战超时」和结算可正常返回。
- [x] **RUN-03 · 第 1 章「点亮江岸」**。检查第 2～4 章、难度 1～4 及三件进度工装的锁定条件。以难度 0 首通第 1 章，结算显示首通额外 +12 凭证，「本局解锁」含第 2 章、阿阮的电工服、磁力抓钩、难度 1「寒潮来袭」。点「下一章」核对出发准备的选中章节。
- [x] **RUN-04 · 第 2 章「抢回急救电池」**。首通后检查第 3 章、冷库焊工服、多路电击针解锁。章节档案显示第 2 章已通。
- [x] **RUN-05 · 第 3 章「夺回广播塔」**。首通后检查第 4 章、老陈的工作服、重型撬棍解锁。章节档案显示第 3 章已通。
- [x] **RUN-06 · 第 4 章「天亮前合闸」**。首通后看到「全城恢复供电」与港区尾声。日志 → 章节档案可见复电插画；出发准备可「换武器」，只能选符合该工装条件的已解锁武器。换一把后进战确认实际起手武器。
- [x] **RUN-07 · 港区无尽**。从出发准备切到「港区无尽」，打过第 12 波后能进入第 13 波，第 15 波出现首领。结算后核对首页和通关记录最高波数，随后用更低成绩结束一局，确认最高纪录保留。
- [x] **RUN-08 · 难度 1「寒潮来袭」**。残血清波，核对回复已损失生命的 18%（测试时避开额外补给或回血效果）。任一章首次通关该难度后，解锁零号线接电钩和难度 2。
- [x] **RUN-09 · 难度 2「清退加急」**。核对商店涨价 10%，第 4 波起出现干扰机。首次达成该档时，解锁急诊稳压器及 +2 配件排除容量；对应章节的加密附件可读。
- [x] **RUN-10 · 难度 3「全区封锁」**。第 5 波精英带护卫，第 8 波另有精英；首通解锁总工的六臂挂架，留货上限 +1。
- [x] **RUN-11 · 难度 4「03:55 最后期限」**。同一首领对比低档，攻击更频繁且弱点暴露窗口更短。首通解锁总闸铜手柄，带上后入波有电震和约 6 秒攻速提升。每章首次达成时金章 +1，集齐四章后首页显示「四章金章已集齐」。
- [x] **RUN-12 · 跨档首通奖励**。先在别章解锁难度 2，再让一章从未通关的状态直接通难度 2。核对首通额外 +50 凭证（12 + 16 + 22），重打同档后该奖励不再出现。可以与 RUN-04 合并试玩。
- [x] **RUN-13 · 付费出发补给**。先用无签到赠送次数的测试档选「备用铜件」，核对扣 15 凭证、开局 +35 铜件。杀进程续玩后余额和开局铜件正确。另测凭证不足且无广告时，底部显示差额且无法出发。

## 4. 战斗手感与像素表现

逐把勾选。远程武器在原地悬浮、左右转向和后坐时观察起点，弹道或效果应从可见枪口／发射端发出。观察同一武器击中后仍存活的敌机和被击毁的敌机，确认命中表现和击毁表现可区分。

- [x] **WPN-01 · 电弧扳手**。触点与挥击轨迹一致。让两台敌机同时进入同一次挥击范围，每台只吃一次伤害。
- [x] **WPN-02 · 重型撬棍**。转向后撬棍触点和扫掠起止位置一致，靠近武器一侧的有效目标优先。
- [x] **WPN-03 · 连锁电弧枪**。首段从枪口出发，后续电弧连接实际受击的敌机。
- [x] **WPN-04 · 气动铆钉枪**。枪口闪光和弹道起点与转向、后坐时的枪口位置一致。
- [x] **WPN-05 · 液压破甲枪**。枪口出弹方向正确，命中反馈在受击敌机上。
- [x] **WPN-06 · 气割焊枪**。贴近目标和角色转向时检查火焰锥，焰根贴住喷嘴，受击范围与画面一致。
- [x] **WPN-07 · 高压吹灰枪**。转向和后坐时脉冲贴住喷嘴，脉冲宽度和方向能指认实际受击区域。
- [x] **WPN-08 · 感应线圈**。旋转时发射端与电效对齐，命中位置能辨认。
- [x] **WPN-09 · 磁力抓钩**。磁力效果从发射端展开，受击目标被向角色拉近。
- [x] **WPN-10 · 多路电击针**。观察同一次多路攻击，各路电效从发射端向实际目标展开。
- [x] **WPN-11 · 槽位与角色方向**。实测单把贴身悬浮，装到两把和六把时等角分布。绕敌机移动和停转时武器随角色平移，各自留在槽位并独立转向，远程枪托朝向合理。角色八向转身、移动和受击时身上无固定武器。
- [x] **WPN-12 · 敌机预警和首领弱点**。检查清道冲车红线、伏击机突袭预警、钢缆回收机绞盘与钢缆。干扰机金圈预警后转紫，在圈内观察攻速降低及连锁电弧被打断。每章首领检查红色预警与实际命中区域、露出弱点提示与可输出时机。绕敌机和首领移动，检查正面、侧面和背面能区分，换向时动作贴图正确。

## 5. 广告、签到与分享

- [x] **RET-01、RET-03 的 Web 部分**。签到、重开、免费补给只消耗一次。模拟微信分享接口收到战报文案并能返回值班室。抖音侧边栏及微信原生分享面板见渠道待办。

- [x] **AD-01 · 无广告配置**。在未配广告位的测试包逐页查看复活、升级、商店、出发准备、结算。广告入口隐藏、无空白按钮或报错，主流程可继续。
- [x] **AD-02 · 普通波复活**。普通波阵亡，完整看完广告后满血重打本波，装备和铜件保留。同局第二次阵亡直接结算。
- [x] **AD-03 · 首领波复活**。先打掉一部分首领血再阵亡并看完广告。原地复活，回复至 60% 生命、有约 2 秒免伤，小怪和弹幕清除，首领的血量保留。
- [x] **AD-04 · 升级与商店**。升级时完整观看「多选一项」，剩余可选数 +1，同局限一次。商店广告每次给 +20 铜件和 1 次免费刷新，同局用完两次后入口隐藏。
- [x] **AD-05 · 出发准备两种广告**。用凭证不足且无签到免费次数的测试档验证「领取补给并出发」；再选已解锁难度下的锁定工装验证「试用」。补给和工装在本局生效，试用结束后工装仍锁定。两入口共用每日 2 次额度。
- [x] **AD-06 · 结算翻倍**。记录本局奖励及余额，完整看完广告只追加基础凭证，首通及今日委托奖励各只计一次。检查「基础奖励已翻倍」、同局只能领一次，完成三次后当天入口隐藏。
- [x] **AD-07 · 取消、弱网、无填充**。在五个点位分别主动提前关闭，核对「看完视频才能领取奖励」清晰可读，约 2.4 秒后消失，奖励和次数无变化。另测无填充或弱网失败，能重试或继续主流程。急救页可点「结束本局」。
- [x] **AD-08 · 切页防误触**。摇杆一直按到阵亡／清波再松手，另测快速连点。急救、商店或结算出现后的约 300 毫秒内，松手和残留点按不会打开广告，稍后主动点击仍有效。
- [ ] **RET-01 · 签到与侧边栏**。当日首次签到 +20 凭证和 1 次免费出发补给，重进后不能再领，免费补给出发后只消耗一次。抖音支持侧边栏的设备从「打开侧边栏」离开，再从侧边栏返回并签到。
- [x] **RET-02 · 今日委托与次日重置**。已有出战记录后打开「今日委托」，核对日期、当日词条和指定工装。首通额外 +35 凭证，当天重打不重复发奖。次日冷启动，检查签到、委托和广告日额度开始新一日。
- [ ] **RET-03 · 分享战报**。微信、抖音真机结算点「分享战报」，确认原生面板出现，战役章节或无尽波数正确，有伤害记录时带主力武器。取消分享后仍可返回值班室。
