## 2. 新号首局与常用操作

- [ ] **NEW-01 · 首次开战**。清空测试档，冷启动看到「江岸维修站 · 凌晨 02:13」。先点「开始抢修」，直接进入第 1 章第 1 波。
- [ ] **NEW-02 · 走位与拾取**。进场先不动，底部移动提示清楚可读。默认摇杆在右侧，拖动约 1 秒后提示消失。松手即停，武器自动攻击，靠近铜件能拾取。
- [ ] **NEW-03 · 第一次升级**。清第 1 波后检查「选择升级」的 4 张卡、剩余可选次数和属性说明，点一次只消耗一次选择机会，选完进入商店。
- [ ] **NEW-04 · 首店合成**。第 1 波后商店左上格提供一阶电弧扳手。买下后两个扳手槽出现绿点。根据信息条选中武器并点「合成升阶」，两个一阶变为一个二阶。点「开始第 2 波」进入战斗。
- [ ] **NEW-05 · 跳过指引**。另开新档，首店点「关闭提示」，提示即时消失。进入下一波再回商店并重启一次，确认指引未重新出现。
- [ ] **NEW-06 · 留货、刷新和拆解**。留货一件后刷新，再进入下一波商店，检查留货、价格和铜件余额；取消留货后可替换。免费刷新优先使用，付费刷新按显示价格扣费。拆解武器后到账与按钮一致。若已能留满货架，全留货时刷新入口应禁用。
- [ ] **NEW-07 · 满槽和羁绊**。装备六把武器，购买可合成的同阶武器后原槽正确升阶；尝试买无法合成的武器，核对货架和余额。切进「属性与羁绊」检查当前效果，再返回商店，确认武器与货架状态一致。
- [ ] **NEW-08 · 工坊、配件排除**。购买一项天赋，检查凭证、升级效果以及进下一局后的实际属性。解锁排除容量后排除一件配件，后续商店刷新并检查其他配件仍能正常出现。

## 4. 战斗手感与像素表现

逐把勾选。远程武器在原地悬浮、左右转向和后坐时观察起点，弹道或效果应从可见枪口／发射端发出。观察同一武器击中后仍存活的敌机和被击毁的敌机，确认命中表现和击毁表现可区分。

- [ ] **WPN-01 · 电弧扳手**。触点与挥击轨迹一致。让两台敌机同时进入同一次挥击范围，每台只吃一次伤害。
- [ ] **WPN-02 · 重型撬棍**。转向后撬棍触点和扫掠起止位置一致，靠近武器一侧的有效目标优先。
- [ ] **WPN-03 · 连锁电弧枪**。首段从枪口出发，后续电弧连接实际受击的敌机。
- [ ] **WPN-04 · 气动铆钉枪**。枪口闪光和弹道起点与转向、后坐时的枪口位置一致。
- [ ] **WPN-05 · 液压破甲枪**。枪口出弹方向正确，命中反馈在受击敌机上。
- [ ] **WPN-06 · 气割焊枪**。贴近目标和角色转向时检查火焰锥，焰根贴住喷嘴，受击范围与画面一致。
- [ ] **WPN-07 · 高压吹灰枪**。转向和后坐时脉冲贴住喷嘴，脉冲宽度和方向能指认实际受击区域。
- [ ] **WPN-08 · 感应线圈**。旋转时发射端与电效对齐，命中位置能辨认。
- [ ] **WPN-09 · 磁力抓钩**。磁力效果从发射端展开，受击目标被向角色拉近。
- [ ] **WPN-10 · 多路电击针**。观察同一次多路攻击，各路电效从发射端向实际目标展开。
- [ ] **WPN-11 · 槽位与角色方向**。实测单把贴身悬浮，装到两把和六把时等角分布。绕敌机移动和停转时武器随角色平移，各自留在槽位并独立转向，远程枪托朝向合理。角色八向转身、移动和受击时身上无固定武器。
- [ ] **WPN-12 · 敌机预警和首领弱点**。检查清道冲车红线、伏击机突袭预警、钢缆回收机绞盘与钢缆。干扰机金圈预警后转紫，在圈内观察攻速降低及连锁电弧被打断。每章首领检查红色预警与实际命中区域、露出弱点提示与可输出时机。绕敌机和首领移动，检查正面、侧面和背面能区分，换向时动作贴图正确。

## 5. 广告、签到与分享

先在 Web 预练操作，再用微信和抖音真实广告验证。测试广告取消、弱网或无填充时记录实际回调场景；条件无法复现的项继续留空。

- [ ] **AD-01 · 无广告配置**。在未配广告位的测试包逐页查看复活、升级、商店、出发准备、结算。广告入口隐藏、无空白按钮或报错，主流程可继续。
- [ ] **AD-02 · 普通波复活**。普通波阵亡，完整看完广告后满血重打本波，装备和铜件保留。同局第二次阵亡直接结算。
- [ ] **AD-03 · 首领波复活**。先打掉一部分首领血再阵亡并看完广告。原地复活，回复至 60% 生命、有约 2 秒免伤，小怪和弹幕清除，首领的血量保留。
- [ ] **AD-04 · 升级与商店**。升级时完整观看「多选一项」，剩余可选数 +1，同局限一次。商店广告每次给 +20 铜件和 1 次免费刷新，同局用完两次后入口隐藏。
- [ ] **AD-05 · 出发准备两种广告**。用凭证不足且无签到免费次数的测试档验证「领取补给并出发」；再选已解锁难度下的锁定工装验证「试用」。补给和工装在本局生效，试用结束后工装仍锁定。两入口共用每日 2 次额度。
- [ ] **AD-06 · 结算翻倍**。记录本局奖励及余额，完整看完广告只追加基础凭证，首通及今日委托奖励各只计一次。检查「基础奖励已翻倍」、同局只能领一次，完成三次后当天入口隐藏。
- [ ] **AD-07 · 取消、弱网、无填充**。在五个点位分别主动提前关闭，核对「看完视频才能领取奖励」清晰可读，约 2.4 秒后消失，奖励和次数无变化。另测无填充或弱网失败，能重试或继续主流程。急救页可点「结束本局」。
- [ ] **AD-08 · 切页防误触**。摇杆一直按到阵亡／清波再松手，另测快速连点。急救、商店或结算出现后的约 300 毫秒内，松手和残留点按不会打开广告，稍后主动点击仍有效。
- [ ] **RET-01 · 签到与侧边栏**。当日首次签到 +20 凭证和 1 次免费出发补给，重进后不能再领，免费补给出发后只消耗一次。抖音支持侧边栏的设备从「打开侧边栏」离开，再从侧边栏返回并签到。
- [ ] **RET-02 · 今日委托与次日重置**。已有出战记录后打开「今日委托」，核对日期、当日词条和指定工装。首通额外 +35 凭证，当天重打不重复发奖。次日冷启动，检查签到、委托和广告日额度开始新一日。
- [ ] **RET-03 · 分享战报**。微信、抖音真机结算点「分享战报」，确认原生面板出现，战役章节或无尽波数正确，有伤害记录时带主力武器。取消分享后仍可返回值班室。
