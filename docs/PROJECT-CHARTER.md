# 《夜班修理局》项目宪章

## 角色朝向与动作

- 主角和有朝向的敌人都支持上、下、左、右及四个斜向。角色站定后保留最后有效朝向。移动用实际位移选方向，攻击用实际出手方向，锁定攻击要遵守预警时的朝向。
- 主角应有待机、移动、出手和受击动作。敌人应有待机、适用的移动方式、攻击和受击动作。冲刺、射击、牵引及关底独有的攻击至少要能看清预备、出手和收招。固定炮台也要能看出炮口朝向和开火反馈。
- 攻击帧跟实际生效时刻对齐，受击帧由实际扣血触发。位移、判定或动画暂停时按同一战斗时钟走。颜色、粒子、位移抖动可强化动作，关键姿势仍应从角色本身看得出来。
- 八个方向都要检查。可镜像对称的造型和动作，持械手、文字、布线或单侧装甲有区别时要保留方向差异。使用统一的脚底或底盘锚点，避免切换方向或受击时跳位。
- 实时 3D 角色按连续角度转向。用八向和相邻方向之间的角度取样，核对模型旋转中心、地面锚点、攻击锁向与预警线。横移躲避时，已经锁定的冲刺和射击按原方向出手。
- 主角和 Boss 优先刻画轮廓、材质分层及能参与动作的零件。小怪以实战尺寸的辨识度为准。攻击和技能要有专门的姿势或机构变化，受击与实际扣血同步。Boss 的技能和受击同刻发生时，保留正在执行的动作并叠加受击反馈。

## 素材验收

- 提交素材时记录来源、许可或原创过程、帧表、锚点和用到的界面。查缺帧、重复姿势、透明边和单位在实际战场上的尺寸，不以图集存在视为通过。
- 先用实际 Creator 浏览器战役复核 360 × 640 和 393 × 852。走八向并停下检查朝向，触发近战、远程和受击检查帧序，记录画面或短片。静音时仍要能看懂危险与命中。真机另复核触控、音频与帧耗。
- 新武器、配件和局外奖励在提交前从正常交互路径验证。从预警看到攻击生效，从结单看到解锁，再到下一次出勤确认奖励可用。
