## 自己试武器

在仓库根目录运行 `node scripts/serve.mjs creator-m0/build/campaign-web-review`，打开[战役](http://127.0.0.1:4173/)或[单武器试打台](http://127.0.0.1:4173/?weaponShowcase=bench)。点武器名换下一把，点配件重新开始相同遭遇，点右侧按钮在怪群和巡检首领间切换。也可直接试[喷火管专属件打首领](http://127.0.0.1:4173/?weaponShowcase=bench&tool=torch&special=1&target=boss)。从新检出的仓库构建时，用 Creator 3.8.8 打开 `creator-m0`，按 `build-campaign-web.json` 构建 Web Mobile 调试包。

单把武器贴在腰侧，两至六把时按装备数量沿圆环等角排列。移动时整组跟随维修工，开火时各自在槽位上瞄准和后坐。可以在[六武器试打台](http://127.0.0.1:4173/?weaponShowcase=utility)观察移动与换向。

同一把武器对着同一位置的炮台开火。左列炮台挨打后留下，右列这一击将它击毁。上排是基础武器，下排装了专属配件。喷火管的强化样片取连续开火后的蓝白焰。每两步取一帧，按慢动作播放。[十把武器命中与击毁对照](review/weapon-hit-and-break.webp)

此前的武器版本另有一组基础武器、专属件和首领装甲的同场对照。[旧版武器慢放](review/campaign-weapon-effects.webp)

## 小怪为什么更多，Boss 怎么变难

- 每波最后增加一次推进。同一侧三队依次从不同位置入场，第四队从两边夹入，下一组换边。第一波就能用起手武器打完整支小队。接近站点末段时，队列混入本站的特殊敌人。每波的商店零件预算沿用上版。
- 配电站同时存活及待入场上限为 20 台。其余第一章关卡上限为 24 台，后三章分别为 28、32、36 台。核心最后阶段仍限制小怪数量，给玩家留出看弹道的空间。
- 首领血量按章节增加，降至约 72% 和 34% 时，两翼先后派出护卫。玩家可以沿射线穿过护卫继续打首领，也可以转身用范围武器清出退路。守卫到场时首领仍能受伤。最后一关的核心有 807 点血，扫线、牵引和环弹仍按其各自的起手和恢复时间出招。

## 十把武器的命中反馈

出手时枪口迸火、抛出弹壳或放电，挥击的刃光跟随接触端。群怪被打散时会翻倒、迸出碎片；同一击拆掉三台及以上会显示实际数量。打在首领装甲上时，重击集中在接触点，弹幕始终画在武器特效上层。

| 武器 | 基础动作 | 对照时看哪里 |
| --- | --- | --- |
| 电弧扳手 | 起手放慢，正反手加速扫过敌群，接触端留下双色弧刃 | 联动齿轮给弧刃加上亮齿；06 的回扫飞轮在一挥扫中两台后，下一挥才扩大弧线并加伤 |
| 旁路扳手 | 反手钩回、提起下压，两种接触路径分别判定 | 重型离合片留下方形锤影，第四次连击命中时从接触点崩出裂纹 |
| 电弧枪 | 放电时抬枪、回弹，闪电逐台连跳 | 跨弧接头沿真实连跳路径劈出青、紫两股电流 |
| 铆钉枪 | 快速后坐再复位，铆钉拖着铜色分节尾迹，优先覆盖同一排敌机 | 贯穿钉组多穿两台，弹道外出现旋转纹 |
| 液压钉枪 | 先顶出再重重回缩，钉头沿一条宽轨穿过前排 | 油压套环在近处加伤；改装后有双轨钉影，双排入钉座还能实际加宽弹道、多穿一台 |
| 喷火管 | 喷嘴左右摆动，火舌在实际扇区内卷出并散成火星 | 高温换向阀连续开火到第四击才变成蓝白焰，停火冷却后重新积热 |
| 脉冲喷管 | 喷口顶出、收缩、回弹，冲击波往外推 | 强排导板打出四层冲击波与朝外的箭脊，推开距离更长 |
| 感应线圈 | 盘体旋转放大，紫色波环从发射端扩至此次放电范围的外沿 | 叠层感应盘形成三层反向转动的电环，半径随配件增长 |
| 牵引线圈 | 线圈先探出再收回，沿实际受击目标拉出绿索 | 重载吸盘用双索和六臂涡纹回收，牵引留出 30 像素缓冲，避免升级后把小怪直接拖到脚上 |
| 分束探针 | 探头左右甩开，每个实际目标分到一支菱形飞针 | 四路分配器可同时锁四台，针尖变为薄荷色，终点出现分叉亮纹 |
