## 战斗时长从哪里来

第一波用起手武器应付一支小队。第二次整备才开放额外武器槽，因此第二波的追加小队固定为四台，避免慢速牵引武器刚出门就把整群小怪吸到自己身上。中后段陆续加入三种变化：普通爬行机护送原有特殊敌人；另一队从新方向赶来；两次紧接的冲击后留出换边的空当。末段可从两个方向同时入场。开场和增援都按击倒数推进，能够更快清群的配置会更早腾出活动空间。

第一至四章每站的同时存活与待入场合计上限分别为 20、24、28、32。小队分排错位进场；爬行机靠得太近会错步，方便辨认群体轮廓。每波掉落零件的预算约为原波次击倒数的 115%，一次击倒十台仍能看到十台倒下，商店购买力单独控制。

首领分别调了血量。巡检机半血后缩短巡逻间隔；各站低血量的扇弹从五发增为七发，环弹从八发增为十二发，第二轮错半个弹道间距。章节首领和普通领队在后段弹幕后更快衔接招牌攻击，每招仍有完整起手，标志动作之后保留近战反打时间。核心经历扇区、钢缆和扫线三阶段。

## 各关怎么变难

同种子改前／改后各测四个种子、两种起手路线。标准购买策略共 160 对关卡样本，均通关。按每次通关汇总后取中位数，前五波总击倒从 170 到 1,173；峰值同屏从 5 到 24；按时间加权的平均同屏从 1.2 到 7.3；单模拟步同时击倒的单关峰值从 2 到 6。首领实际打出的攻击从 3 轮到 5 轮，中位耗时从 12.1 到 21.6 秒。同屏按战斗视口统计，每六个模拟步采样一次。

## 十种攻击与改装后的差别

| 武器 | 基础动作 | 对照时看哪里 |
| --- | --- | --- |
| 电弧扳手 | 起手放慢，正反手加速扫过敌群，接触端留下双色弧刃 | 联动齿轮给弧刃加上亮齿；06 的回扫飞轮在一挥扫中两台后，下一挥才扩大弧线并加伤 |
| 旁路扳手 | 反手钩回、提起下压，两种接触路径分别判定 | 重型离合片留下方形锤影，第四次连击命中时从接触点崩出裂纹 |
| 电弧枪 | 放电时抬枪、回弹，闪电逐台连跳 | 跨弧接头沿真实连跳路径劈出青、紫两股电流 |
| 铆钉枪 | 快速后坐再复位，铆钉拖着铜色分节尾迹，优先覆盖同一排敌机 | 贯穿钉组多穿两台，弹道外出现旋转纹 |
| 液压钉枪 | 先顶出再重重回缩，钉头沿一条宽轨穿过前排 | 油压套环在近处加伤；改装后有双轨钉影，双排入钉座还能实际加宽弹道、多穿一台 |
| 喷火管 | 喷嘴左右摆动，火舌在实际扇区内卷出并散成火星 | 高温换向阀连续开火到第四击才变成蓝白焰，停火冷却后重新积热 |
| 脉冲喷管 | 喷口顶出、收缩、回弹，冲击波往外推 | 强排导板打出四层冲击波与朝外的箭脊，推开距离更长 |
| 感应线圈 | 盘体旋转放大，从角色身边打出带放电齿的紫色波环 | 叠层感应盘形成三层反向转动的电环，半径随配件增长 |
| 牵引线圈 | 线圈先探出再收回，沿实际受击目标拉出绿索 | 重载吸盘用双索和六臂涡纹回收，牵引留出 30 像素缓冲，避免升级后把小怪直接拖到脚上 |
| 分束探针 | 探头左右甩开，每个实际目标分到一支菱形飞针 | 四路分配器可同时锁四台，针尖变为薄荷色，终点出现分叉亮纹 |

## 复跑与验收边界

全战役 1,440 场按三种购买策略各跑 480 场，低购装 463 场通关，标准和高购装各 480 场通关。低购装失败集中在 09、13、17、20。另一个商店实验固定扳手起手，在六站采用添武器、优先改扳手、放开购买三种决策，共 193/216 场通关，其中优先改扳手失败 18 场。真人评审值得重点试一次少武器走 17 的退路，以及成型后 20 的弹缝是否清楚。
