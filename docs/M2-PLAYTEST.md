# M2 完整一局

打开 Creator 3.8.8 工程 `creator-m0/`，预览 `assets/scenes/M2.scene`。构建配置为 `creator-m0/build-m2.json`，抖音本地竖屏调试包输出到 `creator-m0/build/bytedance-mini-game-m2/`。M2 使用独立的 A/B 存档键，旧 M1 灰盒仍可打开。

## 一局流程

- 六波时长为 30 / 40 / 45 / 55 / 60 / 75 秒。前五波存活后进整备，最后一波必须在时限内击败巡检机。生命归零或 Boss 超时进入失败结算。
- 第一波慢爬虫，第二波加入冲车，第三波加入炮台，第四波加入正面减伤的护甲机，第五波混编。巡检机轮换扫线与冲撞，半血后加入召援。普通怪和 Boss 的攻击方向均有视觉预警，冲车、炮台和 Boss 有音效提示。
- 四把工具、12 个模组，最多两把工具且每把两个模组槽。首店保证可负担的配对。第二次整备在有空工具位时至少提供两把候选。可替换非起手模组，每间整备可付费刷新一次。
- 每波开始恢复 10 点生命。拾取的零件和未捡掉落的自动回收在波末统一提交。结算显示逐波击倒、拾取、受击及构筑触发。进程重启回到整备页或当前波起点，当前波内未提交状态随该波重置。

## 本地验证

- Creator 预览实点首店购买和第二工具位，脚本走位通关六波，重载后保留六行结算和通关状态。四个本地提示音资源均已加载。
- TypeScript 及 28 项自动测试通过，包括两条路线按正常战斗步进通关、半血召援、Boss 超时、护甲方向、存档和满槽替换幂等。
- Windows 抖音 IDE 4.5.7 的 iPhone 15 Pro 模拟器已验证首波结算、重编译恢复整备、购买分流器、第二波连锁与胶囊下方的暂停按钮。真机音效、前后台、双端性能回归和 8–12 人诊断试玩待验证。

## 诊断试玩

同一台手机先跑一局电弧或磁吸，下一局换起手路线。记录首波能否无提示完成、首商店能否解释所凑配对、是否主动重开、卡住波次及死因。建议至少一半参与者不熟悉肉鸽。先用 3/4 完成首波、2/3 讲清构筑、1/2 主动重开作为诊断线。

Android 和 iOS 各回归一局，覆盖第五波混编、Boss 预警及半血召援、暂停/切后台返回、整备购买后冷恢复。记录机型、系统、抖音版本和帧耗。调试包在控制台输出 `[M2]` 本地事件 `run_start`、`wave_end`、`shop_pick`、`build_trigger`、`death`、`run_end` 和 `restart`。
