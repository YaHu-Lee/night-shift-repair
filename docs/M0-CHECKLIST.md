# M0 验收记录

2026-11-20：项目负责人确认 M0 实测通过，进入 M1。以下保留 Codex 的独立观测记录。

## 已验证（云端）
- Node 24 严格 TS 检查（纯逻辑、平台适配、共享控制器）。
- 模拟可重放、单位轴/边界、持续压力负载和对象复用；A/B 损坏回退、存储错误及宿主事件接口模拟。
- 120 活敌、160 弹体、80 掉落，固定 30 Hz。Node 纯模拟基准隔离了渲染与宿主，不能用于判断手机帧率。
- UI 集成测试加载真实浏览器入口脚本，在模拟 DOM/Canvas 中验证首屏绘制计数、拖动、暂停继续、前后台、保存并重新启动恢复检查点。套件共 10 项通过。云浏览器未能连到临时本地预览；真实浏览器画面、触屏行为与性能尚未通过验证。

## Windows 本地实测（2026-11-20）
- 基线 `65062b2` 加本地改动。Creator 3.8.8 的标准 2D 场景已保存，360 × 640 浏览器预览显示完整场地与 120/160/80。拖动、松手、暂停继续及保存后重载恢复场景起点已验证。预览容器切页未观察到预期暂停。
- 抖音开发者工具 4.5.7 导入并重新编译，窗口 3，iPhone 15 Pro 模拟皮肤 393 × 852，基础库 4.33.0，`DOUYIN` 宿主。调试构建目录 `creator-m0/build/bytedance-mini-game/` 共 6,591,225 字节。
- 画面与 `[M0]` 日志确认拖动位移、松手清零且角色停住、暂停期间 tick 不增长、手动继续后恢复。通过 IDE 的模拟侧边栏切出再返回，hide/show 均为 tick 4088，返回停在 RESUME，手动点击后继续。
- 运行到 tick 1534 保存。停止并重启模拟器后回到 tick 0，角色位于 (180, 320)，等待手动继续。检查点恢复到压力场景起点。
- 120/160/80 连续两轮，时长 60.002 s 和 60.003 s，分别采集 3554 和 3555 个帧间隔。两轮 p95 均为 17 ms，峰值均为 35 ms。模拟器结果独立于真机验收。
- 测试号已生成扫码预览码。Android、iOS 真机和冷启动五次统计均待测。
