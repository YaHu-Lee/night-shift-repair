## 验收边界

首局从空档点开始，用固定种子覆盖新手有足够铜件买扳手的分支。章节用战斗内核实际打完前 11 波生成存档，浏览器从第 12 波开头接手。四章都要通过真实的首领战、结算、解锁和重启检查。广告、工坊和复活另外使用定点测试档。正常试玩包关闭调试，测试从画布点按出发，直接读取经过校验的游戏存档来判断是否开战。

用例完整定义见[上线清单](PRE-LAUNCH-CHECKLIST.md)。本次执行限 Web。平台原生广告、设备性能及系统音频中断留在原清单。Web 堆采样只涵盖 Chrome 的 JavaScript 堆。

## 本地证据

**DEV-09** 首页和商店各静置 180 秒，每 30 秒读一次 Chrome JavaScript 已用堆，首尾主动触发 GC。四组场景结束后按钮仍可操作。

| --- | ---: | ---: | ---: |
| 短屏首页 | 9.6 MiB | 36.8 MiB | 11.2 MiB |
| 长屏首页 | 10.1 MiB | 43.5 MiB | 11.1 MiB |
| 短屏商店 | 10.9 MiB | 39.7 MiB | 15.6 MiB |
