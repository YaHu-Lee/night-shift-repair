# 主角工装图集

五张透明 PNG 原稿由 GPT Image 为本项目生成。每张从上到下为值班服工具带、钢衬肩甲、电工线圈、焊罩、回收袋、测绘标杆，从左到右为 I–IV 阶。侧面稿用于约束两张斜向稿的形状、配色与附件层次。

| 原稿 | 方向 |
| --- | --- |
| gear-source.png | 正面 |
| gear-back.png | 背面 |
| gear-side.png | 向右 |
| gear-ne.png | 右后 |
| gear-se.png | 右前 |

`pack.py` 按固定格子裁出附件、清理半透明边缘、用最近邻规范像素尺寸，输出到首章分包的 `pixel/rigs`。运行时按工装、阶级、朝向取帧，配合主角本体动作的脚底锚点和步态起伏。西侧三个方向镜像东侧原画。武器使用独立挂点。
