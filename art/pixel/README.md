# 战役像素化进度

| 范围 | 正式战役接入 |
| --- | --- |
| 维修工和武器 | 维修工空手八向，10 把独立悬浮武器，可同时装备 6 把 |
| 普通敌机 | 爬行机、冲锋机、炮台、装甲机、追击机、回收机、干扰机、伏击机 |
| Boss | 配电站巡检机、分站主管、封锁领队、并联守门机、拖拽回收车、静默阵列、调度核心 |
| 地面和场景 | 四章二十站地面、路线图、通电街区结局，以及机柜、运输车、升降台等任务物件 |
| 战斗特效 | 每把武器各自的动效、接触火星和命中颗粒、刷怪提示、瞄准、敌弹、导电标记、炮带、索线与扇面 |
| 掉落、装备、配件 | 零件、7 件通用装备、40 件武器专属配件、共享分流接头和 3 张开班蓝图 |
| UI | 值班室、战斗 HUD、整备台、派遣、档案和委托图标、对讲头像、通电结局 |

新敌机与 Boss 使用固定斜俯视八方向。对称视图可从对应的原生方向反射。炮口、底盘和危险方向按战斗状态核对。武器使用一张可旋转的侧视贴图。

常规战役构建默认使用像素画面。3D 对照构建仍从 `Campaign3D` 场景进入。
