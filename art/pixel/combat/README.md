# 战斗像素素材

四章二十张地面取自 2026-11-24 的 Codex 内置 GPT ImageGen 输出。地面以 330 × 325 画布、最多 28 色和最近邻取样显示，对齐 660 × 650 的战斗坐标。战斗域控制墙体、障碍和预警。

敌机与 Boss 按固定斜俯视绘制。先制作 N、NE、E、SE、S 五个独立方向，再镜像西侧三向。每套独立动作以底盘锚点和该机的统一像素比例切帧。敌机图集按完整角色分页，每页高度不超过 2048 像素。冲锋标记按冲锋步长、车身边距和障碍裁剪。装甲机读取护盾减伤方向，炮台和分站主管在预警及发动阶段保留锁定朝向。

原始图放在 `sources/`，切帧与调色参数在 `manifest.json`。提示词和来源记录见[来源记录](sources.md)。保存生成工具的原始输出与摘要，工具未返回可验证的模型版本。

```powershell
python art/pixel/combat/assemble.py art/pixel/combat/manifest.json art/pixel/combat/candidate
```

正式导出用 `--runtime` 过滤候选敌机，再将接入项的图集、帧表和地面贴图同步到 Creator 章节分包的 `pixel/`。环境贴图按所处章节分包，共用战斗素材放在第一章分包。运行时延续现有战斗动作、碰撞和 UI 交互。

值班室、整备台、对讲头像、四章地图和通电结局按原型重绘。第一章地图按原有高度拆成两片，站点点击位置沿用战役坐标。派遣插画从各站点周围裁取，与地图共用色板。开班蓝图与导电标记和其他物品一起切帧，状态与文字由代码绘制。

配件在武器训练、整备库存和安装位置复用同一正式配件标识。四十件专属配件各有图标，分流接头在各工具之间共享。任务道具跟随现有任务坐标，状态标记和可用范围由战斗域驱动。

2026-11-24 用 Creator 3.8.8 浏览器调试包验证二十站出勤、战斗底图和整备，以及末站的结局插画，覆盖 360 × 640 和 393 × 852 两种竖屏尺寸。模拟步复核敌机和 Boss 八向绑定、预警与攻击朝向、装甲减伤，以及调度核心三阶段的扇面、索线和炮带。小游戏真机验收待完成。
